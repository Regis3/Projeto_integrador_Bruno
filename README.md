# organização de rotas de ônibus
Etapa_1
# Sobre o projeto
O projeto tem como objetivo organizar as rotas dos ônibus de uma escola, facilitando o transporte dos alunos.
# Problema
A escola pode ter dificuldades para organizar os alunos, os pontos de parada, os horários e as rotas dos ônibus.
# Objetivo
Criar um sistema que permita organizar e consultar as rotas, horários, alunos e pontos de parada dos ônibus escolares.
# Público-alvo
Alunos, responsáveis e funcionários da escola.
