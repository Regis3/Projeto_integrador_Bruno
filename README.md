# Sobre o projeto
O projeto Organização de Rotas de Ônibus tem como objetivo facilitar a organização e a consulta das rotas de transporte coletivo. A proposta é desenvolver um sistema que permita visualizar informações sobre linhas, trajetos, pontos de parada e horários dos ônibus.
Problema
Muitas pessoas enfrentam dificuldades para encontrar informações sobre as rotas de ônibus, como qual linha utilizar, onde embarcar, quais pontos fazem parte do trajeto e os horários disponíveis. Essas dificuldades podem causar atrasos e tornar o deslocamento mais complicado.
Objetivo
Criar uma solução simples para organizar as informações das rotas de ônibus, permitindo que os usuários encontrem com mais facilidade a linha e o trajeto que precisam utilizar.
# Funcionalidades
Cadastro e organização das linhas de ônibus.
Consulta das rotas disponíveis.
Visualização dos pontos de parada.
Consulta dos horários das linhas.
Busca de uma rota de acordo com o local de origem e destino.
Exibição das informações de forma organizada e fácil de entender.
# Público-alvo
O sistema será destinado principalmente a pessoas que utilizam o transporte público e precisam consultar informações sobre as rotas de ônibus.
# Benefícios
A organização das informações pode facilitar o planejamento dos deslocamentos, reduzir dúvidas sobre as linhas e ajudar os usuários a encontrar uma rota adequada para chegar ao seu destino.
