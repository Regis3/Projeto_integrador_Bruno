# 1. Descrição do sistema
O sistema de Organização de Rotas de Ônibus será desenvolvido para organizar e disponibilizar informações sobre linhas, trajetos, pontos de parada e horários do transporte coletivo.
# 2. Requisitos funcionais
1. **Cadastro de linhas**
O sistema deverá permitir o cadastro das linhas de ônibus, contendo informações como número ou nome da linha.
2. **Cadastro de rotas**
O sistema deverá permitir cadastrar o trajeto realizado por cada linha.
3. **Cadastro de pontos**
O sistema deverá permitir registrar os pontos de parada pertencentes a cada rota.
4. **Consulta de linhas**
O sistema deverá permitir que o usuário consulte as linhas disponíveis.
5. **Consulta de horários**
O sistema deverá apresentar os horários de funcionamento das linhas cadastradas.
6. **Busca de rota**
O sistema deverá permitir que o usuário informe um local de origem e um destino para encontrar uma opção de rota.
7. **Exibição das informações**
O sistema deverá apresentar de maneira organizada os dados da linha, seus pontos de parada e horários.
# 3. Requisitos não funcionais
1. **Usabilidade**
O sistema deverá possuir uma interface simples e fácil de utilizar.
2. **Organização**
As informações das linhas e rotas deverão ser apresentadas de forma clara e organizada.
3. **Desempenho**
As consultas deverão apresentar os resultados de forma rápida.
4. **Segurança**
O sistema deverá proteger as informações cadastradas contra alterações não autorizadas.
# 4. Usuários do sistema
1. Usuário comum: poderá consultar linhas, rotas, pontos de parada e horários.
2. Administrador: poderá cadastrar, alterar e organizar as informações das linhas, rotas, pontos e horários.
